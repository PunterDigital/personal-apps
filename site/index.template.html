Installing unsigned builds

Windows: if SmartScreen says "Windows protected your PC", click More info → Run anyway.

macOS: open the .dmg, drag the app to Applications, then right-click the app → Open → Open. If macOS says the app is damaged, run xattr -dr com.apple.quarantine "/Applications/<App>.app" in Terminal.
